# Videobereich online unkenntlich machen

Schützen Sie Ihre Privatsphäre, indem Sie bestimmte Bereiche Ihres Videoclips unkenntlich machen. Die Verarbeitung erfolgt vollständig in Ihrem Browser, um 100%ige Sicherheit zu gewährleisten.

HTML: https://grepcut.com/de/tools/blur-region-video

## So machen Sie einen bestimmten Bereich in Ihrem Video online unscharf

1. **Video hochladen**: Wählen Sie eine MP4-, MOV-, WebM- oder MKV-Datei von Ihrem Gerät aus und laden Sie sie in den Vorschau-Arbeitsbereich.
2. **Unschärfe-Box platzieren**: Ziehen Sie das Rechteck über das Gesicht, das Kennzeichen, das Dokument, das Passwort, das Logo oder den Bildschirmbereich, den Sie verbergen möchten, und passen Sie die Größe an.
3. **Unschärfestärke anpassen**: Erhöhen Sie die Unschärfe, wenn der Text oder das Gesicht noch lesbar ist, oder verringern Sie sie, wenn Sie nur eine dezente Privatsphäre-Maske benötigen.
4. **MP4 exportieren**: Klicken Sie auf „Bereich unscharf machen & exportieren“, um die Pixel lokal in Ihrem Browser zu verarbeiten und das fertige MP4 herunterzuladen.

Dieses Tool eignet sich am besten, wenn der sensible Bereich an einer Stelle bleibt, z. B. ein Kennzeichen in einer Dashcam-Aufnahme, ein Eck-Wasserzeichen, ein feststehendes Webcam-Gesicht oder ein auf einem Schreibtisch sichtbares Dokument.

## Wenn Sie eine saubere Unschärfe-Box benötigen, keinen vollwertigen Video-Editor

Wenn Sie nur einen Bereich verbergen müssen, kann das Öffnen eines vollwertigen Timeline-Editors aufwändiger sein als die eigentliche Aufgabe. Vielleicht müssen Sie ein Kennzeichen abdecken, bevor Sie eine Fahrzeugaufnahme teilen, ein Namensschild in einer Arbeitsaufnahme unkenntlich machen oder ein Passwort verbergen, das während der gesamten Aufnahme auf dem Bildschirm sichtbar ist.

GrepCut hält diesen Arbeitsablauf direkt. Sie platzieren einen rechteckigen Unschärfebereich in der Vorschau, wählen die gewünschte Unschärfestärke und exportieren ein neues MP4 mit den bearbeiteten Videopixeln.

Ihre Datei bleibt auf Ihrem Gerät, während das Tool im Browser arbeitet. Das ist wichtig, wenn das, was Sie verbergen, vor der Bearbeitung sensibel ist - nicht erst danach.

### Verwenden Sie es für feststehende oder weitgehend feststehende Details

- **Gesichter in statischen Aufnahmen**: Decken Sie ein Gesicht in einer Webcam-, Interview-, Unterrichts-, Meeting- oder Überwachungsaufnahme ab, wenn das Gesicht im selben Bereich bleibt.
- **Kennzeichen und Adressen**: Verbergen Sie ein Kennzeichen, eine Hausnummer, ein Lieferetikett, eine Rechnung oder andere private Details, bevor Sie den Clip posten oder versenden.
- **Bildschirme und Dokumente**: Machen Sie ein Anmeldefeld, einen privaten Chat, eine Tabellenzelle, einen Kundennamen, ein internes Dashboard oder eine in der Aufnahme sichtbare Dokumentecke unscharf.

Wenn sich das Motiv über das Bild bewegt, reicht ein statisches Rechteck möglicherweise nicht aus. Verwenden Sie für bewegte Gesichter oder Kennzeichen stattdessen das Tracking in [GrepCut Studio](/).

## Statische Unschärfe-Box vs. Tracking-Unschärfe

| Anforderung | Dieses Tool verwenden, wenn | Tracking verwenden, wenn |
| --- | --- | --- |
| Ein fester Bereich | Das sensible Detail bleibt während des gesamten Clips innerhalb eines Rechtecks. | Das Detail bewegt sich über den Bildschirm oder ändert seine Größe. |
| Schnelle Privatsphäre-Bearbeitung | Sie möchten eine schnelle Bearbeitung im Browser ohne eine Zeitleiste anzulegen. | Sie benötigen Keyframes, Masken oder szenenweise Anpassungen. |
| Mehrere Gesichter | Sie müssen nur eine Gruppe oder einen festen Bereich abdecken. | Sie benötigen separate Unschärfebereiche für mehrere bewegte Gesichter. |
| Überprüfungsaufwand | Sie können einen Bereich einmal prüfen und dann exportieren. | Sie müssen den Clip durchgehen und bestätigen, dass die Unschärfe dem Motiv folgt. |

Eine statische Unschärfe-Box ist einfach, weil sie weniger leistet. Das ist der Vorteil, wenn Ihr privates Detail feststeht, und die Einschränkung, wenn es sich bewegt.

## Warum lokale Verarbeitung hilft, bevor Sie teilen

Eine Privatsphäre-Bearbeitung hat ein Timing-Problem: Das Originalvideo ist vor dem Anwenden der Unschärfe sensibel. Wenn Sie den Rohclip zuerst an einen entfernten Editor hochladen, könnte die unverpixelte Version bereits außerhalb Ihrer Kontrolle sein.

Bei diesem browserbasierten Tool erfolgt die Bildverarbeitung lokal. Sie können eine teilbare Version erstellen, ohne die Originaldatei an GrepCut-Server zu senden.

Für stärkere Privatsphäre überprüfen Sie das exportierte Video vor der Veröffentlichung. Eine Unschärfe über Gesicht oder Kennzeichen hilft, aber Ihr Clip könnte dennoch Identität preisgeben - durch Stimmen, ausgesprochene Namen, Hintergrundschilder, Spiegelungen, Uniformen oder Ortshinweise.

## Vorteile des Tools „Video-Bereich unscharf machen“

### Advantages

- Ihr Video wird lokal im Browser verarbeitet, kein Upload.
- Sie können die Unschärfe-Box direkt in der Vorschau ziehen und in der Größe anpassen.
- Sie können die Unschärfestärke vor dem Export ändern.
- Das Tool ist kostenlos und ohne Wasserzeichen.
- Die Audiospur bleibt erhalten, während die Videopixel bearbeitet werden.

### Disadvantages

- Es wird nur ein rechteckiger Unschärfebereich angewendet.
- Der Unschärfebereich ist statisch, folgt also keinem bewegten Motiv.
- Der Export erfolgt als MP4, auch wenn Ihre Eingabedatei einen anderen Container verwendet.

## FAQ: Video-Bereich unscharf machen

### Kann ich nur einen Teil eines Videos unscharf machen?

Ja. Sie können eine rechteckige Unschärfe-Box über den Bereich legen, den Sie verbergen möchten, Größe und Stärke anpassen und dann das bearbeitete MP4 exportieren.

### Wird mein Video während der Unschärfe hochgeladen?

Nein. Die Verarbeitung läuft lokal in Ihrem Browser, Ihre Originaldatei wird nicht an GrepCut-Server gesendet.

### Kann ich ein bewegtes Gesicht oder Kennzeichen unscharf machen?

Dieses Tool verwendet eine statische Box, funktioniert also am besten, wenn Gesicht, Kennzeichen oder privates Detail an einer Stelle bleiben. Wenn sich das Motiv bewegt, öffnen Sie [GrepCut Studio](/) und verwenden Sie stattdessen Tracking.

### Kann ich mehrere Bereiche im selben Video unscharf machen?

Dieses Tool auf der Landingpage wendet einen rechteckigen Unschärfebereich an. Wenn Sie mehrere Unschärfezonen, separate Masken oder getrackte Objekte benötigen, verwenden Sie [GrepCut Studio](/).

### Entfernt oder ändert das Unschärfe-Tool meine Audiospur?

Nein. Das Tool ändert die Videopixel im ausgewählten Bereich und behält die Audiospur unverändert bei.

### Welche Videoformate kann ich laden?

Sie können gängige Videodateien wie MP4, MOV, WebM und MKV laden. Das verarbeitete Ergebnis wird als MP4 exportiert.

### Wie stark sollte die Unschärfe sein?

Stellen Sie die Unschärfe hoch genug ein, dass Gesicht, Kennzeichen, Dokument oder Bildschirmtext in der Vorschau nicht lesbar sind. Überprüfen Sie bei sensiblen Aufnahmen das exportierte MP4, bevor Sie es teilen.

### Reicht Unschärfe immer für die Privatsphäre?

Unschärfe kann die ausgewählten Pixel verbergen, aber Ihr Video könnte dennoch Informationen preisgeben - durch Stimmen, Namen, Spiegelungen, Schilder, GPS-ähnliche Umgebungen oder anderen Kontext. Prüfen Sie das gesamte Bild vor der Veröffentlichung.
