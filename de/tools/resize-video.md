# Video online skalieren

Verkleinern oder vergrößern Sie Ihren Clip prozentual und sehen Sie die neue Auflösung sowie die geschätzte Dateigröße vor dem Export. Die Verarbeitung erfolgt lokal in Ihrem Browser - kein Hochladen, kein Wasserzeichen.

HTML: https://grepcut.com/de/tools/resize-video

## So skalieren Sie ein Video online

1. **Video hinzufügen**: Ziehen Sie Ihre Datei in das Tool oder klicken Sie zum Durchsuchen. Das Video wird lokal auf Ihrem Gerät verarbeitet.
2. **Prozentsatz wählen**: Wählen Sie 10 %, 25 %, 50 %, 75 %, 125 %, 150 %, 200 % oder 400 %. Sie können die Originalauflösung sofort mit der erwarteten Ausgabe vergleichen.
3. **MP4 exportieren**: Klicken Sie auf „Anwenden“, um das skalierte MP4 herunterzuladen, oder öffnen Sie den Clip in GrepCut Studio, wenn Sie weiterbearbeiten möchten.

Benötigen Sie eine benutzerdefinierte Leinwand, einen Zuschnitt oder eine Neupositionierung anstelle einer einfachen Skalierung? Öffnen Sie Ihren Clip in [GrepCut Studio](/).

## Skalieren Sie Ihr Video ohne Verzerrung

Dieses Tool skaliert prozentual, sodass Breite und Höhe gemeinsam geändert werden. Ihr Video behält sein ursprüngliches Seitenverhältnis, wodurch verzerrte Gesichter, ovale Kreise und schwarze Balken vermieden werden, die auftreten, wenn ein Clip in die falsche Form gezwungen wird.

Verwenden Sie „Skalieren“, wenn Sie denselben Bildausschnitt wünschen, nur kleiner oder größer. Wenn Sie einen vertikalen Clip für Reels, einen quadratischen Beitrag, eine 16:9-Leinwand oder einen manuellen Zuschnitt benötigen, öffnen Sie die Datei stattdessen in GrepCut Studio.

### Enthaltene Voreinstellungen:

- **10 % bis 25 %**: Machen Sie einen sehr großen Clip viel kleiner für schnelles Teilen, grobe Überprüfung oder Uploads mit geringer Bandbreite.
- **50 % bis 75 %**: Reduzieren Sie einen 4K- oder hochauflösenden Export, während Sie einen gut sichtbaren Bildausschnitt für Web, E-Mail und soziale Beiträge beibehalten.
- **125 % bis 200 %**: Erstellen Sie einen größeren Bildausschnitt, wenn Ihre Quelle für den gewünschten Upload-Ort etwas zu klein ist.
- **400 %**: Nutzen Sie die maximale Hochskalierung für sehr kleine Quellclips, wobei die Qualität weiterhin durch die Originaldatei begrenzt ist.

Vor dem Export sehen Sie die Original- und die erwartete Auflösung nebeneinander sowie eine geschätzte Ausgabegröße.

## Warum Skalieren das Teilen Ihrer Datei erleichtern kann

Ein kleinerer Bildausschnitt hat weniger Pixel pro Videobild, sodass der Encoder weniger visuelle Informationen speichern muss. Deshalb kann das Verkleinern das Hochladen Ihrer Datei in Chat-Apps, E-Mails, Kursportale oder soziale Plattformen erleichtern.

Die Schätzung basiert auf der Pixelanzahl und ist daher nützlich, um vor dem Export einen Maßstab zu wählen. Die endgültige Datei kann dennoch variieren, da Bewegung, Audio, Quellkomprimierung und Encodereinstellungen das fertige MP4 beeinflussen.

### Eine praktische Regel:

- **Zu groß zum Senden**: Versuchen Sie es zuerst mit 50 % oder 75 % und prüfen Sie dann, ob die Vorschauauflösung noch ausreicht.
- **Bereits unscharf**: Vermeiden Sie starkes Hochskalieren. Ein größerer Bildausschnitt erzeugt keine echten Details, die nie aufgezeichnet wurden.
- **Benötigt eine andere Form**: Verwenden Sie stattdessen Zuschnitt- oder Leinwandwerkzeuge anstelle der prozentualen Skalierung.

## Welchen Skalierungsprozentsatz sollten Sie wählen?

| Ihr Ziel | Guter Startmaßstab | Was Sie erwarten sollten |
| --- | --- | --- |
| Schnelle Vorschau oder E-Mail-Anhang | 10 % oder 25 % | Ein viel kleinerer Bildausschnitt und eine viel kleinere Datei, am besten zur Überprüfung und nicht zur endgültigen Veröffentlichung geeignet. |
| 4K-Clip für Upload verkleinern | 50 % oder 75 % | Ein kleineres MP4, das normalerweise genügend Details für den alltäglichen Web-Sharing behält. |
| Kleinen Clip an größeres Layout anpassen | 125 % oder 150 % | Ein größerer Bildausschnitt ohne neue erfasste Details, nützlich, wenn die Quelle nahe an Ihrer Zielgröße liegt. |
| Kleinen Quellclip maximieren | 200 % oder 400 % | Eine größere Ausgabe, die je nach Original weicher oder stärker komprimiert wirken kann. |

Für plattformspezifische Zuschnitte wie 9:16, 1:1 oder 16:9 verwenden Sie [Video zuschneiden](/tools/crop-video) oder öffnen Sie den Clip in [GrepCut Studio](/).

## Ihr Video bleibt auf Ihrem Gerät

Die Skalierung erfolgt in Ihrem Browser, sodass Ihre Datei nicht auf einen Server hochgeladen wird. Das ist wichtig, wenn Ihr Clip privates Filmmaterial, Kundenmaterial, eine Kursaufzeichnung oder eine große Datei enthält, deren Übertragung zu lange dauern würde.

Da die Verarbeitung lokal erfolgt, hängt die Leistung von Ihrem Computer oder Telefon ab. Große 4K-Dateien benötigen mehr Arbeitsspeicher, und die Exportgeschwindigkeit hängt von der Browserunterstützung und der hardwarebeschleunigten Codierung ab, sofern verfügbar.

Für den reibungslosesten Export verwenden Sie einen WebCodecs-fähigen Browser wie Chrome, Edge oder Opera.

## Browser-Videoskalierung auf einen Blick

### Advantages

- Private Verarbeitung ohne Upload.
- Live-Vorschau der Auflösung und geschätzten Dateigröße.
- Einfache Prozentvoreinstellungen von 10 % bis 400 %.
- Exportiert ein standardmäßiges MP4 ohne Wasserzeichen und ohne Konto.

### Disadvantages

- Sehr große 4K-Dateien sind vom Gerätespeicher abhängig.
- Hochskalieren kann fehlende Details der Quelle nicht wiederherstellen.
- Prozentuale Skalierung schneidet nicht zu, füllt nicht auf und ändert das Seitenverhältnis nicht.
- Export erfordert einen WebCodecs-fähigen Browser.

## Video online skalieren - FAQ

### Kann ich ein Video skalieren, ohne es hochzuladen?

Ja. Ihr Video wird in Ihrem Browser verarbeitet, sodass es auf Ihrem Gerät bleibt. Sie laden nur das neue MP4 herunter, wenn Sie exportieren.

### Wird die Videodatei durch Skalieren kleiner?

Das Verkleinern macht die Datei oft kleiner, da die Ausgabe weniger Pixel pro Bild hat. Die genaue Größe hängt dennoch von Bewegung, Audio und der MP4-Codierung des Browsers ab.

### Wird mein Video gestreckt?

Nein. Die Skalierung ändert Breite und Höhe um denselben Prozentsatz, sodass das ursprüngliche Seitenverhältnis erhalten bleibt.

### Kann ich ein 4K-Video auf 1080p skalieren?

Ja, wenn der gewählte Prozentsatz in die Nähe dieses Ziels kommt. Beispielsweise wird aus einem 3840×2160-Clip bei 50 % ein 1920×1080-Clip.

### Kann ich hier ein Querformat-Video in ein Hochformat-Video umwandeln?

Nicht allein mit der prozentualen Skalierung. Verwenden Sie [Video zuschneiden](/tools/crop-video) oder GrepCut Studio, wenn Sie eine 9:16-, 1:1- oder benutzerdefinierte Leinwand benötigen.

### Verbessert eine 200%ige oder 400%ige Hochskalierung die Qualität?

Sie vergrößert den Bildausschnitt, erzeugt aber keine Details, die in der Quelle fehlen. Wenn das Original unscharf oder stark komprimiert ist, kann der größere Export dennoch weich wirken.

### Warum weicht die exportierte Dateigröße von der Schätzung ab?

Die Schätzung basiert auf der Auflösungsänderung. Die tatsächliche Ausgabegröße kann abweichen, da Videoinhalt, Audio, Quellkomprimierung und Browser-Codierung das endgültige MP4 beeinflussen.

### Welches Format erhalte ich?

Sie erhalten ein standardmäßiges MP4 mit H.264-Video, das für breite Wiedergabe und saubere Uploads auf gängigen Plattformen ausgelegt ist.
