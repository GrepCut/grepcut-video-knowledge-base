# 無料オンラインビデオツール | GrepCut

ブラウザベースの無料ビデオツール - トリミング、クロップ、リサイズ、ミュートなど。すべてデバイス上で処理。

HTML: https://grepcut.com/ja/tools


## Highlights

### デフォルトでプライベート

動画はデバイス上で処理され、どこにもアップロードされません。

### インストール不要、サインアップ不要

ページを開いてファイルをドロップするだけで、すぐに編集を開始できます。

### 対応ブラウザで高速

WebCodecsにより、利用可能な環境ではスムーズで応答性の高い処理を実現します。

## ツールを選ぶ

- [ビデオトリマー](https://grepcut.com/ja/tools/video-trimmer.md) - 2秒以内に動画を必要な部分だけにカット。ロスレスキーフレームアライメントストリームコピーを使用し、すべてブラウザ内でローカル処理されるため、アップロード不要で画質劣化もありません。 (https://grepcut.com/ja/tools/video-trimmer)
- [動画クロップ](https://grepcut.com/ja/tools/crop-video.md) - 切り抜きボックスをドラッグするか、ソーシャルメディアのアスペクト比を選択して動画をリフレーム。すべてブラウザ内で処理され、アップロードも透かしも不要です。 (https://grepcut.com/ja/tools/crop-video)
- [動画リサイズ](https://grepcut.com/ja/tools/resize-video.md) - クリップをパーセンテージで縮小または拡大し、エクスポート前に新しい解像度と推定ファイルサイズを確認できます。ブラウザ内でローカル処理されるため、アップロードも透かしも不要です。 (https://grepcut.com/ja/tools/resize-video)
- [動画回転](https://grepcut.com/ja/tools/rotate-video.md) - 横向きのスマホ動画を正しい向きに直したり、クリップを反転してSNS投稿用に調整。ブラウザ内で完結処理 - アップロード不要、透かしなし。 (https://grepcut.com/ja/tools/rotate-video)
- [動画無音化](https://grepcut.com/ja/tools/mute-video.md) - ロスレスコンテナリマックスで瞬時に動画から音声を除去。すべてデバイス上でローカル処理 - アップロード不要、画質劣化なし、透かしなし。 (https://grepcut.com/ja/tools/mute-video)
- [動画速度変更](https://grepcut.com/ja/tools/change-video-speed.md) - タイムラプスを高速化したり、リプレイをスロー再生したり、ブラウザ上で任意のクリップを調整できます。高速モードでは再エンコードせずにタイミングを変更するため、画質はそのまま維持されます。再エンコードモードでは互換性のあるH.264 MP4を作成し、両モードでピッチ補正されたオーディオを提供します。 (https://grepcut.com/ja/tools/change-video-speed)
- [動画に音声を追加](https://grepcut.com/ja/tools/add-audio-to-video.md) - 動画と音声ファイルをドロップするだけで、GrepCutが映像を再エンコードせずにサウンドトラックを置き換えます。データはデバイスから外部に出ることはありません。 (https://grepcut.com/ja/tools/add-audio-to-video)
- [SRT字幕を動画に焼き込む](https://grepcut.com/ja/tools/burn-srt-subtitles-to-video.md) - 動画とSRTファイルをドロップするだけで、GrepCutが全フレームにSRT字幕を焼き付けます。アクセシビリティ向上、SNS共有、無音再生プラットフォームに最適です。 (https://grepcut.com/ja/tools/burn-srt-subtitles-to-video)
- [グレースケール動画](https://grepcut.com/ja/tools/grayscale-video.md) - あらゆる動画をクラシックなグレースケールに変換。すべての処理はデバイス上でローカルに実行され、アップロードや透かし、アカウント登録は一切不要です。 (https://grepcut.com/ja/tools/grayscale-video)
- [着信音メーカー](https://grepcut.com/ja/tools/ringtone-maker.md) - 任意のトラックから完璧な40秒のスニペットを選び、iPhone用.m4rまたはAndroid用.mp3の着信音としてエクスポート。アップロード不要、アプリのインストールも不要。 (https://grepcut.com/ja/tools/ringtone-maker)
- [オーディオビジュアライゼーション](https://grepcut.com/ja/tools/audio-visualization.md) - STFT周波数マッピングでトラックを解析し、4つのWebGLスペクトラムスタイルをリアルタイムでプレビュー。同期オーディオ付きの30fps H.264 MP4にエクスポートできます。アップロード不要。 (https://grepcut.com/ja/tools/audio-visualization)
- [顔ぼかし](https://grepcut.com/ja/tools/face-blur.md) - MediaPipe BlazeFaceがフレームごとに顔を検出し、プライバシー保護のぼかしを適用します。群衆、インタビュー、Bロールを手動でマスクすることなく匿名化できます。 (https://grepcut.com/ja/tools/face-blur)
- [動画ぼかし](https://grepcut.com/ja/tools/blur-video.md) - クリップ全体に調整可能なガウシアンブラーを適用。すべての処理はお使いのデバイス上でローカルに実行されます。アップロード不要、透かしなし、アカウント不要。 (https://grepcut.com/ja/tools/blur-video)
- [動画領域ぼかし](https://grepcut.com/ja/tools/blur-region-video.md) - 動画クリップの特定の領域をぼかしてプライバシーを保護します。すべてブラウザ内で処理されるため、100%安全です。 (https://grepcut.com/ja/tools/blur-region-video)
- [動画モザイク加工](https://grepcut.com/ja/tools/pixelate-video.md) - クリップの全フレームにモザイク効果を適用。すべての処理はお使いのデバイス上でローカルに実行されます。アップロード不要、透かしなし、アカウント不要。 (https://grepcut.com/ja/tools/pixelate-video)
- [音声ノイズ除去](https://grepcut.com/ja/tools/audio-noise-remover.md) - デバイス上のスペクトラルノイズリデューサーで、あらゆるオーディオファイルからバックグラウンドのヒス、ハム、ファンノイズ、静電気を除去します。エクスポート前に効果を確認できます。アップロード不要、透かしなし、アカウント不要。 (https://grepcut.com/ja/tools/audio-noise-remover)
- [オーディオノーマライザー](https://grepcut.com/ja/tools/audio-normalizer.md) - 統合ラウドネスを測定し、トラックを-14、-16、または-23 LUFSにノーマライズします。アップロード不要、アカウント不要でブラウザ上で完全に動作します。 (https://grepcut.com/ja/tools/audio-normalizer)
- [FSR動画アップスケーラー](https://grepcut.com/ja/tools/video-upscaler.md) - ブラウザ上でエッジ適応型FSRアップスケーリングにより動画の解像度を向上。 (https://grepcut.com/ja/tools/video-upscaler)
- [AI画像アップスケーラー](https://grepcut.com/ja/tools/ai-image-upscaler.md) - Real-CUGAN超解像技術で写真やグラフィックを高画質化。端末上でローカル処理するため、アップロード不要、透かしなし。または高速キャンバスモードで素早く3倍書き出し。 (https://grepcut.com/ja/tools/ai-image-upscaler)
