## Cara Mengonversi Video ke WAV di Browser Anda

1. **Pilih file video Anda**: Letakkan file MP4, MOV, WebM, atau MKV ke dalam konverter, atau pilih dari perangkat Anda dengan penjelajah file.
2. **Atur output WAV**: Pilih mono atau stereo, pilih sample rate yang Anda butuhkan, dan pilih PCM WAV 16-bit atau 24-bit sebelum mengonversi.
3. **Ekstrak audio**: GrepCut membaca video Anda secara lokal, mendekode jalur audio, membuang jalur video, dan menulis hasilnya sebagai file WAV tak terkompresi.
4. **Unduh WAV Anda**: Simpan audio yang diekstrak ke perangkat Anda. Video asli dan file WAV baru Anda tetap lokal selama proses berlangsung.

Konversi berjalan dengan teknologi browser seperti WebCodecs dan WebAssembly. Karena file Anda tidak diunggah ke server, Anda dapat mengekstrak audio dari rekaman pribadi, wawancara, kuliah, atau materi klien dengan risiko lebih kecil.

## Kapan Anda Harus Mengekstrak WAV dari Video

Jika Anda perlu mengedit, membersihkan, mencampur, mengarsipkan, atau mentranskripsi audio dari video, WAV adalah format kerja yang praktis. Ini memberikan sampel PCM terdekode yang dapat ditangani oleh editor audio, alat transkripsi, dan proses produksi secara terprediksi.

Jika video Anda berasal dari kamera, perekam layar, aplikasi rapat, atau ekspor pengeditan, audio sering disimpan di dalam wadah yang lebih besar dengan bingkai video, subtitle, bab, atau metadata. Mengonversi video ke WAV memberi Anda hanya trek audio, sehingga Anda dapat bekerja dengan suara tanpa membawa seluruh file video.

WAV bukan pemulihan kualitas ajaib. Jika audio sumber Anda sudah dikompresi sebagai AAC, Opus, atau codec lossy lainnya, mengonversi ke WAV tidak akan mengembalikan detail yang telah dihilangkan sebelumnya. Yang dilakukannya adalah menghindari penambahan langkah kompresi lossy lain setelah dekode.

### Gunakan WAV saat Anda menginginkan hasil edit yang bersih, bukan file terkecil.

Untuk berbagi di ponsel atau aplikasi pesan, MP3 mungkin lebih kecil. Untuk pengeditan, restorasi, transkripsi, dan pengarsipan, WAV sering menjadi file perantara yang lebih aman.

## Memilih Sample Rate, Saluran, dan Bit Depth

Jika Anda menyiapkan ucapan untuk transkripsi, mono sudah cukup dan membuat WAV lebih kecil. Jika sumber Anda memiliki informasi saluran kiri dan kanan yang penting, pilih stereo agar file Anda mempertahankan tata letak tersebut.

Untuk sample rate, 44,1 kHz umum untuk proses musik dan 48 kHz umum untuk proses video. Rate yang lebih rendah dapat berguna untuk file hanya ucapan, tetapi mengurangi bandwidth audio yang tersedia setelah konversi.

Pilih 16-bit saat Anda membutuhkan kompatibilitas luas dan WAV yang lebih kecil. Pilih 24-bit jika Anda berencana melakukan lebih banyak pengeditan atau pemrosesan dan menginginkan headroom ekstra dalam file kerja.

Pengaturan terbaik tergantung pada apa yang akan Anda lakukan selanjutnya. Jika Anda mengirim WAV ke editor video atau stasiun kerja audio, sesuaikan pengaturan yang diharapkan oleh proses tersebut.

## Kelebihan dan Keterbatasan Konversi Video ke WAV

### Advantages

- Video Anda tetap di perangkat selama konversi
- Anda mendapatkan file khusus audio untuk diedit, dibersihkan, dicampur, atau ditranskripsi
- PCM WAV menghindari encode lossy lain setelah audio sumber didekode
- Anda dapat memilih tata letak saluran, sample rate, dan output 16-bit atau 24-bit

### Disadvantages

- File WAV lebih besar dari MP3 atau file audio lossy lainnya
- WAV tidak dapat memulihkan detail yang telah dihilangkan oleh codec sumber yang terkompresi
- Video yang sangat panjang mungkin memakan waktu lebih lama karena browser dan perangkat Anda yang melakukan pekerjaan
- Konverter hanya mengekstrak audio, sehingga tidak membuat file video baru

## FAQ Konverter Video ke WAV

### Bisakah Anda mengonversi MP4 ke WAV?

Ya. Anda dapat memilih file MP4 dan mengekstrak audionya sebagai file PCM WAV tak terkompresi langsung di browser Anda.

### Bisakah Anda mengekstrak WAV dari MOV, WebM, atau MKV?

Ya. GrepCut mendukung ekstraksi video ke WAV dari file **MP4, MOV, WebM, dan MKV**. Konverter membaca kontainer video yang didukung dan menulis audio yang didekode sebagai WAV.

### Apakah video Anda akan diunggah?

Tidak. File Anda tetap di perangkat Anda. GrepCut melakukan konversi secara lokal di browser Anda, sehingga Anda tidak perlu mengunggah rekaman pribadi ke server.

### Apakah mengonversi video ke WAV meningkatkan kualitas audio?

Ini menghindari penambahan langkah kompresi lossy lain, tetapi tidak mengembalikan detail yang hilang. Jika video Anda sudah berisi audio terkompresi, WAV akan berisi hasil dekode dari sumber tersebut.

### Haruskah Anda memilih WAV 16-bit atau 24-bit?

Pilih **16-bit** untuk kompatibilitas luas dan file lebih kecil. Pilih **24-bit** jika Anda berencana mengedit, memproses, atau mencampur audio yang diekstrak dan menginginkan file kerja dengan ruang kepala lebih tinggi.

### Haruskah Anda mengonversi ke mono atau stereo?

Pilih **mono** untuk ucapan, wawancara, kuliah, atau transkripsi saat pemisahan kiri dan kanan tidak penting. Pilih **stereo** saat sumber Anda memiliki informasi saluran kiri dan kanan yang berarti.

### Apakah ada batasan panjang video?

Tidak ada batasan unggahan server karena konversi terjadi secara lokal. File yang sangat panjang masih membutuhkan lebih banyak waktu dan tergantung pada browser, memori, dan kinerja perangkat Anda.

### Bisakah Anda mengedit video sebelum mengekstrak WAV?

Ya. Anda dapat membuka GrepCut Editor terlebih dahulu untuk memotong, memangkas, atau menggabungkan klip, lalu mengekspor proses audio yang Anda butuhkan dari materi yang telah diedit.
