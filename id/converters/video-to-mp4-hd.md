## Pilih Preset HD yang Sesuai dengan File Anda

**HD 720p** adalah pilihan praktis saat Anda menginginkan MP4 yang lebih kecil untuk pesan, pemutaran seluler, atau transkode browser cepat.

**Full HD 1080p** adalah target harian teraman saat Anda menginginkan MP4 yang terlihat bagus di laptop, TV, dan proses unggah tanpa membebani browser Anda sebanyak 4K.

**Ultra HD 4K / 2160p** memberi Anda bingkai target terbesar. Gunakan saat sumber Anda sudah beresolusi tinggi atau spesifikasi pengiriman Anda meminta 4K, dan perkirakan pemrosesan lebih lama pada klip panjang.

Jika video asli Anda 480p atau 720p, meningkatkan skalanya ke 1080p atau 4K mengubah dimensi output, bukan detail sebenarnya yang ditangkap dalam sumber. Simpan file master Anda saat kualitas penting.

## Kapan 4K Layak dan Kapan Tidak

Pilih 4K saat sumber Anda sudah 4K, proyek Anda memerlukan file 2160p, atau Anda menyiapkan serah terima beresolusi tinggi. Browser Anda membutuhkan lebih banyak waktu CPU dan memori untuk jalur ini, terutama pada klip panjang.

Pilih 1080p saat Anda menginginkan MP4 yang masih terlihat bersih tetapi selesai lebih cepat. Untuk berbagi sosial, ulasan klien, klip kelas, dan pemutaran sehari-hari, Full HD biasanya merupakan kompromi yang lebih baik.

Pilih 720p saat kecepatan dan ukuran lebih penting daripada jumlah piksel. MP4 720p bisa lebih mudah dikirim, dipratinjau, dan disimpan, terutama saat video asli Anda sudah beresolusi rendah.

## FAQ Video ke MP4 HD

### Bisakah Anda mengonversi video ke MP4 1080p di browser?

Ya. Pilih Full HD 1080p, dan GrepCut mengenkode MP4 H.264 + AAC secara lokal di browser saat file Anda perlu transkoding. Jika MP4 atau MOV Anda sudah cocok dan stream kompatibel, GrepCut dapat melakukan remux.

### Bisakah Anda mengonversi video ke MP4 4K?

Ya, pilih Ultra HD 4K / 2160p. Gunakan untuk klip pendek atau desktop yang mumpuni jika memungkinkan, karena pemrosesan 4K membutuhkan lebih banyak memori dan waktu CPU daripada 720p atau 1080p.

### Apakah menaikkan skala video ke 1080p atau 4K akan membuatnya lebih tajam?

Tidak dengan sendirinya. Menaikkan skala meningkatkan ukuran bingkai, tetapi tidak dapat memulihkan detail yang hilang dari sumber beresolusi rendah. Jika klip 480p Anda dienkode sebagai 1080p, file tersebut lebih besar dalam dimensi, bukan otomatis lebih jelas.

### Haruskah Anda memilih 720p, 1080p, atau 4K?

Pilih 720p untuk file lebih kecil, 1080p untuk berbagi sehari-hari, dan 4K hanya jika Anda memerlukan hasil 2160p atau sumber Anda sudah beresolusi tinggi. Jika kecepatan penting, 1080p biasanya merupakan target browser yang lebih aman.

### Kapan konversi menjadi remux alih-alih transkode penuh?

Untuk input MP4 dan MOV, GrepCut dapat mengemas ulang stream yang ada jika tingginya sudah cocok dengan preset yang dipilih dan codec kompatibel. Jika file perlu penskalaan atau perubahan codec, maka harus melakukan transkode.

### Mengapa GrepCut menggunakan FFmpeg.wasm untuk beberapa file?

Beberapa kontainer lawas tidak tercakup oleh jalur asli browser. FFmpeg.wasm dapat mendekode dan mengonversi format seperti AVI, WMV, dan MPEG di dalam browser Anda, lalu menulis MP4 yang diskalakan.

### Apakah video Anda diunggah selama konversi HD?

Tidak. GrepCut menjalankan konversi di tab browser Anda melalui WebCodecs, Mediabunny, atau FFmpeg.wasm. File Anda tetap lokal di perangkat Anda.

### Bisakah Anda mempertahankan kualitas asli?

Jika GrepCut dapat melakukan remux, stream dikemas ulang tanpa perubahan ukuran atau penyandian ulang. Jika file Anda diskalakan atau ditranskode, MP4 baru bersifat lossy, jadi simpan file asli Anda jika Anda mungkin membutuhkannya nanti.
