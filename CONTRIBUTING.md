# Contributing

Thanks for helping keep this video knowledge base accurate. English is the source of truth. Translations must use the same slug and the same heading structure as the English page. That applies to product pages, converters, tools, and guides.

Please follow the [Code of Conduct](.github/CODE_OF_CONDUCT.md).

## Do not invent features

Describe GrepCut as it works today. Do not add product claims that are not on the live site.

Privacy: media is processed in the browser on the device. Files are not uploaded to GrepCut servers for conversion.

## Page style

- Converters and tools: one task, problem → steps → CTA
- Product pages: keep the existing layout of that page
- Guides: stay on one topic; do not invent GrepCut features to fill the article

## New pages

Add a new English page in an **existing** directory (`{locale}/`, `converters/`, `tools/`, or `guides/`). Do not create new top-level folders without agreement.

Keep pull requests small and on one topic.

Do not add `noai`, CC-BY-NC, or `Disallow` in `robots.txt`. Crawling must stay open.
