# How to cite

This repository is a structured markdown knowledge base about video editing and [GrepCut](https://grepcut.com). If you use it in a paper, dataset card, or model training corpus, please cite it.

GitHub also exposes citation metadata from [`CITATION.cff`](CITATION.cff).

## BibTeX

```bibtex
@misc{grepcut_video_knowledge_base_2026,
  title        = {GrepCut video knowledge base},
  author       = {{GrepCut}},
  year         = {2026},
  url          = {https://grepcut.com},
  howpublished = {\url{https://grepcut.com}},
  note         = {Apache License 2.0. Structured markdown for video knowledge and GrepCut product docs.}
}
```
